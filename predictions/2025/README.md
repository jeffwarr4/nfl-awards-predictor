# 2025 NFL season: final board

`board_mvp_final.csv` is the model's final MVP top 10 for the 2025 season, from the run of 2026-01-06 (after week 18,
every player through his full schedule). It was saved from git history (commit e24258e,
`outputs/mvp_predictions_2025_top10.csv`, the pre-2026 layout) and renamed to the 2026 board's column names so the
site's Past Results page can read it. Passer rating and TD:INT are blank for non-quarterbacks. Nothing writes to this
folder; it is frozen.
